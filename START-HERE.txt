처음 실행하는 법 — Windows
==========================

1. ZIP 파일의 압축을 풉니다.
   권장 위치: 문서\dark-water-review-blog

2. Visual Studio Code를 실행합니다.

3. 위쪽 메뉴에서 다음을 누릅니다.
   File → Open Folder

4. 방금 압축을 푼 dark-water-review-blog 폴더를 선택합니다.

5. Visual Studio Code 위쪽 메뉴에서 다음을 누릅니다.
   Terminal → New Terminal

6. 화면 아래쪽에 열린 터미널에 다음 한 줄을 입력하고 Enter를 누릅니다.

   node preview.mjs

7. 아래 주소가 표시되면 Ctrl 키를 누른 채 주소를 클릭합니다.

   http://localhost:4321

8. 미리보기를 끄려면 터미널을 클릭하고 Ctrl + C를 누릅니다.

※ npm install은 하지 않습니다.
※ Docker도 사용하지 않습니다.


블로그 이름과 저자명 바꾸기
==========================

site.config.json 파일을 엽니다.

"name": "Scriptorium"
"author": "YOUR NAME"

이 두 부분을 원하는 이름으로 바꿉니다.
따옴표와 쉼표는 지우지 마십시오.


리뷰 글이 있는 곳
=================

source\reviews 폴더 안의 .md 파일이 리뷰 글입니다.
기존 파일 하나를 복사한 뒤 이름과 내용을 바꾸면 새 글이 됩니다.

글 맨 위의 형식:

---
title: "글 제목"
slug: "주소에 쓸 영문 이름"
date: "2026-08-06"
category: "GAME · 추천"
media: "게임"
summary: "목록에 표시할 짧은 소개"
imagePosition: "50% 50%"
---

media에는 애니, 웹툰, 게임, 소설, 만화, 영화, 드라마, 넷플릭스, 뮤지컬, 연극, 여행 중 하나를 적습니다.
카탈로그의 분류 버튼이 이 값을 사용합니다.

첫 번째 이미지는 자동으로 다음 세 곳에 사용됩니다.
- 메인페이지 썸네일
- 아티클 최상단 큰 이미지
- 아티클 하단 캐러셀

이미지 파일은 source\images 폴더에 넣습니다.
본문에서는 이렇게 작성합니다.

![이미지 설명](images/파일이름.jpg)

파일 이름에는 한글과 공백보다 영문 소문자와 하이픈을 권장합니다.
예: lies-of-p-cover.jpg

글이나 이미지를 바꾼 뒤에는 실행 중인 미리보기를 Ctrl + C로 끄고,
다시 node preview.mjs를 입력하면 변경사항이 반영됩니다.
